1. Introduction
Diabetic Retinopathy (DR) is one of the serious complications of Diabetes and if not diagnosed and treated in early stages of the disease, it can lead to severe visual defects or even to blindness. It happens when the blood vessels in the retina are damaged because of the high blood sugar for a long time. Retinal fundus images can be used to diagnose DR.
Traditional screening involves ophthalmologists using manual inspection to look at retinal images. This can be a lengthy process to carry out, particularly if there are many patients to be screened. The aim of the proposed project is to create a Diabetic Retinopathy Screening System based on Deep Learning to automatically analyze retinal fundus images and estimate the severity of DR.
The algorithm involves image preprocessing and transfer learning with EfficientNetB0 to recognize retinal images at different levels of severity. To get a visual explanation of the model's prediction, we use Grad-CAM. A Streamlit web app enables users to upload retinal photos and get a screening result aided by the AI.
2. Problem Statement
The process of manual exam of the fundus is time consuming and needs medical expertise if there are a lot of patients to be screened.
Therefore, there is an urgent need of an automated system which can:
Analyse images of the back of the eye.
•
Identify possible diabetic retinopathy.
•
Describe the classification of the severity of DR.
Make consistent computer-aided predictions.
•
Assist in prioritizing images that may need further professional evaluation.
The project is designed to create an automated screening system based on Deep Learning techniques for the identification and classification of DR from the fundus images of retina.

5. Proposed System
We will present a system based on Deep learning for automatic analysis of retinal fundus images.
The user uploads a retinal image on the Streamlit web app. The image is preprocessed first by resizing followed by appropriate handling of the image quality and then normalised. The processed image is then passed on to the trained EfficientNetB0 model.
The model is designed to identify key visual features from an image and categorize it into one of the five stages of DR.After classification, the system displays:
•
Predicted severity class.
•
Prediction confidence.
•
Grad-CAM visualization of regions that affect the prediction.
Thus, the proposed system is capable of prediction and with visualization of the prediction.
5. Literature Review
The use of retinal fundus images for the screening of Diabetic Retinopathy (DR) is another significant field of Artificial Intelligence and Deep Learning. However, traditional screening involves trained ophthalmologists or graders examining the image of the retina, which can be time consuming if many patients need screening. Therefore, automated Deep Learning systems for detecting and grading DR have been explored.
The other study based on the EfficientNet proposed an end-to-end diagnostic system for diabetic retinopathy (DR) grading and detection of macular edema (ME) and applied Grad-CAM to visualize the influential areas of the image. The study shows how EfficientNetB0 and explainable AI approaches can be integrated to carry out retinal image analysis. But the study was based on fluorescein angiography images while the present project is based on retinal fundus photograph. The findings, therefore, support the technical approach, but fail to fully address the specific fundus-image screening workflow proposed in this project.

Research Gap
Current studies reveal that, Deep Learning already has a great potential for automated DR screening. But a number of issues still lie ahead. First, automated DR detection and screening for DR are well established, and detailed, five-class severity classification is challenging because of the similarities in characteristics between adjacent disease classes. Second, class imbalance may cause a decrease in performance for the less-represented severe disease classes. Third, the image quality differences and/or acquisition device, population, clinical environments may affect the generalization of the model. Lastly, even though the explainability methods like Grad-CAM have been explored, an integrated and user friendly screening prototype based on classification, confidence information and explainability is still useful for academic and research purposes.
In the context, the present project would like to develop end-to-end prototype for screening retinal fundus image using Deep Learning. Pre-processing and data augmentation are done prior to transfer learning using EfficientNetB0 to classify the images into five DR severity categories. The Grad-CAM is embedded to visualize the prediction of the model and the Streamlit interface allows the user to upload retinal images and then display the severity, confidence score and visualization.
However, for the proposed work, it proposes to concentrate on a new Deep Learning architecture for the integration of already existing Deep Learning methods into a simple, explainable and easy to use academic screening system for students. This system is designed
for academic and research use and will undergo external and clinical testing prior to use in the real world for medical applications.

10. Limitations of the System
The proposed system has certain drawbacks:
Data Dependency
: The model's performance is dependent on the properties of the training set.
2.
Class imbalance
: There can be a smaller number of images per category for some severe DR categories, which can impact prediction performance.
3.
Generalization issues
: The model may not perform the same for images of the retina taken by different cameras, different demographics, or different clinical situations.
No substitute for doctors: The system is not a substitute for an ophthalmologist or clinical exam.
5.
Clinical validation required
: The prototype is suitable for academic/research screening and will need to be clinically validated before it can be used in the medical field.

12. Conclusion
Diabetic Retinopathy Screening Using Deep Learning project aims to develop an AI-powered tool for analysis of the fundus images of retina and categorize them according to the severity of DR.
The project will consist of Python, Computer Vision, Deep Learning, Transfer Learning, Explainable AI, and Streamlit to create an end-to-end screening app. EfficientNetB0 is used for image classification and Grad-CAM is used for a visual explanation of the models' predictions.
The project demonstrates how Deep Learning can be applied to automating the screening process for retinal images and emphasizes that this is a prototype academic/research system and not medical diagnosis.
